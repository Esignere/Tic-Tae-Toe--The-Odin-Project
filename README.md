# Tic-Tac-Toe

A classic Tic-Tac-Toe game built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

## 🎮 About the Project

This project recreates the classic Tic-Tac-Toe game, where two players take turns marking spaces on a 3×3 board. The goal is to be the first player to align three symbols horizontally, vertically, or diagonally.

The project was developed to practice JavaScript fundamentals, DOM manipulation, event handling, and game logic.

## ✨ Features

- Interactive 3×3 game board.
- Two-player gameplay using X and O.
- Automatic win detection.
- Draw detection when the board is full.
- Score tracking for both players.
- Reset button to start a new round.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone (https://github.com/Esignere/Tic-Tae-Toe--The-Odin-Project)
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Start playing!
